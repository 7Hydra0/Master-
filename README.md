# Conselho Master — Portal Institucional

Protótipo de portal institucional do Conselho Master, com página pública,
carta institucional e painel administrativo de demonstração.

## Estrutura

- `index.html` — portal público
- `carta.html` — carta institucional
- `admin.html` — painel administrativo (demonstração local)
- `style.css` — estilos globais
- `admin.css` — estilos do painel
- `script.js` — interações do portal
- `admin.js` — lógica do painel (localStorage)
- `assets/images/` — logo (GIF) e favicon (PNG)

## Como rodar localmente

1. Clone o repositório.
2. Abra `index.html` no navegador, ou use um servidor local:
